# CodSoft AI Internship – Task 1: Rule-Based Chatbot

## Project Overview
This is a **Rule-Based Chatbot** developed as part of the CodSoft AI Internship (AI Domain).  
The chatbot responds to user queries using predefined rules in Python, helping to demonstrate basic **natural language processing** and **conversation flow**.

---

## Features
- Responds to greetings (`hi`, `hello`)  
- Provides chatbot information (`what is your name`)  
- Replies to user status queries (`how are you`)  
- Handles exit commands (`bye`, `exit`, `quit`)  
- Provides default response for unrecognized queries  

---

## Technologies Used
- **Python 3.12+** (Recommended)  
- **Rule-based logic** using `if-else` statements  
- Can be run in **VS Code, PowerShell, or any Python IDE**
